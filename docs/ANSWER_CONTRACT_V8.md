# 答案契约 v8：短输出请求与默认字数下限

[20 题开发 pilot v1](SYSTEM_ONE_LAUNCH_DEVELOPMENT_V1_REPORT.md) 首题请求“一句道歉开头”，两路回答都被 v7 的默认“至少 140 字”判为契约失败。这是任务要求与默认字数规则冲突，而非模型生成失败。

v8 将“写一句”“压缩成三句”纳入有限的句数推断；明确要求一句、一条、一段话、简短、简单、只要、只需、模板或句式的普通请求，推断的最短长度降为 1 字符。详细计划等未命中这类短输出请求时仍沿用 140 字下限。精准句数、引用、其他结构与安全要求保持独立检查。

这是有边界的中文启发式，不能覆盖所有简短意图，也不保证回答质量。契约版本升级为 `answer-verification-contract-v8`，历史 v7 标签保留原判断。对应一题、三句和详细计划的本地回归通过；真实模型表现需在独立的 v2 开发运行中验证。
