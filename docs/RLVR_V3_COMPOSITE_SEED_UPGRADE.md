## 契约升级

每条 v2 种子新增 `route_expectation`，记录：

- 预期执行模式；
- 检出的能力域；
- 最多选择的三个专业 Agent；
- 最小能力域门槛和确定性路由契约版本。

每条预期多 Agent 种子必须有至少两个不同的知识章节 SHA-256。回放器会拒绝来源指纹
缺失、重复或不足的 v2 复合种子。普通生成器不合成安全任务，避免把缺少安全依据的知识
片段伪装成安全训练证据。

知识库同时新增了独立的育儿协作章节，覆盖照护任务、共同排班、替补、育儿预算和定期
复盘，避免育儿契约只出现在问题中、参考上下文却没有直接依据。
