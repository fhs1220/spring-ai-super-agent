# 答案契约 v5：固定五题之后的工程修复

本轮只做免费、本地工程回归；没有新调用生成模型、Jev、Laya、Judge 或 embedding，
没有训练、人工审批、扩样或覆盖旧实验。旧五题仍是开发集，不能据此声称质量提升。

## 变更

- `answer-verification-contract-v5`：同一有效契约传入 single 生成、multi 专家与综合、
  审查、修复及候选选择。专家仍返回 JSON 贡献，最终答案契约不替代专家接口格式。
- `taskFormat`（也接受 `task_format`）增加精确句数、逐周检查点、双方负担对照。
  旧 JSON 和八参数构造调用仍可读取/编译；重新运行使用 v5，不追溯重算旧 v4 结果。
- `deterministic-rlvr-selector-v7`：对丢失任务结构的候选增加惩罚，防止通过删掉周次等
  必需内容获得长度优势。两个候选都不合格时仍可能返回其中一个，但保留契约失败，
  不将其自动改为通过，也不补写虚构内容。
- 综合提示从首稿开始约束长度；生成/综合不加无关介绍，审查压缩时保留任务结构。
- 修复亚毫秒综合步骤被轨迹遗漏的问题：是否记录取决于是否进入综合，而非整数耗时大于零。
- 聊天助手气泡支持 Markdown 标题、粗体、列表、引用块、表格、代码块和流式内容更新。
  原始答案数据不改写，用户消息仍是 Vue 文本插值。

## 确定性检查的范围

| 任务 | 触发与检查 | 边界 |
| --- | --- | --- |
| 精确句数 | 识别“整理成四句”等有限表达；显式值 1–10；检查终止标点、句数、尾部文本、部分套话 | 默认不再强求 140 字或从“三个诉求”推导三个行动项；不证明语义是不指责的表达 |
| 逐周计划 | 问题同时含周数和“每周/逐周检查点”；显式值 1–12；独立 `第N周：` 标题，顺序、行动、检查点 | 拒绝合并/重复/缺周；每段内容长度只是启发式，不证明行动可行或检查点有效 |
| 双方负担 | 问题含“双方”“负担”“可比较”；两人三项指标的 Markdown 表格及调整条件 | 仅识别下述窄格式，不验证计算、公平、帮手次数、预算或事实真实性 |

负担对照支持的格式如下（未知数据必须待填，不为过检查编造数值）：

```markdown
| 指标 | A | B |
| --- | --- | --- |
| 学习小时/周 | 待填 | 待填 |
| 夜醒次数/周 | 待填 | 待填 |
| 家务照护小时/周 | 待填 | 待填 |
若记录显示一方超过双方协商的负担上限，调整下一周分工。
```

左右列也接受甲/乙、我/伴侣等预设名称；单元格接受非负数字、待填、待记录。
散文对照、任意人名、额外列、带单位的数值单元格等尚不支持。单位写在指标列。
调整条件检测仅是关键词结构检查，不能代替人工审查具体阈值、周期、计算和可执行性。
自动推断只是有限中文规则，不是通用自然语言解析；复杂、否定或多重数量要求需显式契约
和人工核对。显式数量与推断数量冲突时拒绝合并，不静默覆盖。

修复项有稳定 ID，例如 `format-exact-sentences`、`format-week-order`、`format-week-6`、
`format-workload-comparison`。这些检查不构成事实、引用、安全或语义质量认证。

## Markdown 安全边界

解析器固定为 `markdown-it@15.0.2`，禁用原始 HTML、自动链接及额外插件；链接仅允许
HTTP(S)、mailto 和锚点，外链带 `noopener noreferrer`。图片只显示替代文本，不自动加载。
唯一 `v-html` 入口接收上述解析器的输出，不接收模型原文。显示 `[来源 n]` 不代表引用已核实。
未来启用 HTML、图片或插件必须重新审查这条边界。
