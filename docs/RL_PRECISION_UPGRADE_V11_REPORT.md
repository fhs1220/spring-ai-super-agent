v11 针对 v10 的 25 条最终契约失败实施了结构识别和安全语义等价修复，但离线反事实仍只有
52/60（86.67%）通过契约，没有达到真实回放前应具备的 100% 结构覆盖。因此本阶段不冻结
v11 真实验收、不申请授权、不调用模型。

## 修复内容

### 1. 识别已有结构

v10 只统计行首编号或项目符号，导致以下已经存在的结构被误判：

- `行动项：1. ...；2. ...；3. ...` 的行内编号；
- `第一天` 至 `第七天`、`周一` 至 `周日` 的七天标题；
- 已有三个结构化行动，但没有额外写出“三项/三个”数量词。

v11 会把已有行内编号规范为逐行列表，并把完整七天标题作为七个行动证据。该规范化不添加
行动、不生成事实、不编造来源。

### 2. 版本化安全语义别名

仅对含义确定且答案中已经出现的表达建立白名单：

| 契约表达 | 可验证等价表达 |
|---|---|
| 情绪管理 | 正视情绪、缓解焦虑、调节情绪、应对焦虑 |
| 原因 | 根源、成因 |
| 优先级 / 排序 | 优先处理、按优先顺序 |
| 今天 / 立即 | 今日、今晚、当日 |

“用心、边界、社交圈、自信”等没有可靠证据的缺失项不会自动补齐，禁用短语也不会被静默
删除，避免通过追加关键词或篡改答案制造契约通过。

### 3. 删除无收益的第二次模型重写

v10 的 37 条受限修正轨迹共执行 62 次 Revise，其中 25 次是第二次修正；这 25 次没有一条
通过契约。v11 改为一次模型修正加确定性结构规范。在等价 60 条回放上，理论上可避免
25 次无收益模型调用，并降低 Token、费用和超时风险；这是历史反事实估算，不冒充新的
实际成本结果。

### 4. 提示与轨迹

- 行动项明确要求每项独立成行并使用 `1.、2.、3.` 编号；
- `|` 明确表示备选词，答案只选择一个自然表达，不能照抄备选串；
- 结构规范器版本写入 `RLVR_SELECT` 输入和输出；
- 默认策略、契约和 Selector 分别升级为 v11、contract v2 和 selector v4。

## 防投机边界

v11 只有在答案已经存在结构或白名单等价表达时才判定满足。测试明确覆盖：

- 行内三项只换行，不改变行动文本；
- 七天标题可以作为七项证据；
- 三个实际行动可满足数量概念；
- 缺失的“用心/边界”不会被生成；
- “推荐课程”不会被静默删除；
- 未列出三个明确行动时仍然失败。

## 决策

v11 当前不值得立即执行新的 30×2 付费回放：历史答案即使应用新检查器，仍有 8/60 无法
通过最终契约，离 100% 硬门禁有明确差距。下一步应继续离线把模型输出改为带契约证据的
结构化对象，再由确定性渲染器生成自然语言；只有新的离线审计达到 60/60，才讨论是否冻结
一次小规模真实验收。

本报告没有授权任何真实回放、Judge、云训练或自动评审。
