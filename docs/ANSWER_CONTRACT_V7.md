# 答案契约 v7：尾部邀请检测漏口

[五题 v3 预检](SYSTEM_ONE_PILOT_V3_REPORT.md) 的 case03 Multi 最终答案包含“如果你愿意，下一条我可以直接帮你写……”式无关尾部邀请，但 v6 `no-assistant-boilerplate` 检查返回通过。原正则只允许“如果你愿意”与“我可以”之间有标点或空白，漏掉“下一条”等短插入语。

v7 在原有规则内允许“下一条、接下来、之后、后续、稍后”出现在这两个片段之间，仍要求后续出现助手提供服务的表达。对话话术“如果你愿意，我想听听你的感受”继续允许。`AnswerVerificationContract.VERSION` 升为 `answer-verification-contract-v7`，使新旧契约判断可按版本区分。

这是针对已观察错误的有限格式修复，不证明所有尾部邀请、安全建议或引用语义已被检查。v3 原始 v6 结果保持不变；新代码对该句的单元回归通过，完整 Java 回归通过。20 条开发 pilot 才能检验新版本在真实生成中的表现。
