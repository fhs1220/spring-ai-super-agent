# RLVR v3 真实试回放报告

## 实验结论

2026-07-28 使用本地 `agentic-rag-v5` 对 5 个知识库合成种子各回放 2 轮，共产生
10 条真实 Agent 轨迹。10 条全部完成、策略版本一致、无超时，契约级 RLVR v3
硬门禁通过率为 100%。

该试验验证了“离线种子 → durable 真实回放 → 轨迹核验 → RLVR 契约评分 → 遥测归档”
链路可以运行，但不能用于证明多 Agent 优于单 Agent：本批 10 条请求均被确定性路由为
`SINGLE_AGENT`。

## 发现与修正

试回放前的在线奖励平均值为 0.9203，但在线奖励没有逐项执行种子中的验证契约。审查后
修正了两个会让量化数据虚高的问题：

1. Reward 现在逐项检查 `required_concepts`、`forbidden_phrases`、
   `minimum_action_items`、`no_follow_up` 和 `must_mark_assumptions`；
2. 引用验证同时识别云端 `[1]` 和本地答案真实使用的 `[来源 1]`。

由于奖励语义发生变化，新实现版本化为 `human-light-rlvr-v3`，避免把 v2 和 v3 的结果
混在同一实验中。修正后 10 条轨迹的平均 RLVR 为 0.759098，更适合作为后续筛选与四臂
实验依据。

## 扩量门禁

当前不建议立即把前 50 个种子各回放 2 轮。现有种子覆盖知识主题和题型，但首批样本都是
单一能力域，无法验证或训练自适应多 Agent 路由。

> 2026-07-29 更新：以下离线种子门禁已经完成，结果见
> [复合多 Agent 种子 v2 升级报告](RLVR_V3_COMPOSITE_SEED_UPGRADE.md)。
> 尚未进行新一轮真实模型回放。

进入 50 题阶段前应先完成：

1. 增加关系沟通、育儿、家务、家庭财务的复合种子，并保留双来源指纹；
2. 按预期路由分层抽样，确保 `SINGLE_AGENT` 与 `ADAPTIVE_MULTI_AGENT` 都有真实轨迹；
3. 安全任务单独成层，不从缺少安全依据的普通知识片段中合成；
4. 先 Dry Run 输出各能力域和预期执行模式分布，再显式授权真实回放。
