概念、返回无法匹配的证据，或偶发无法解析的结构化载荷。渲染器没有凭空生成事实或建议，
所以这些轨迹被硬门禁正确拒绝。

## 决策与后续处置

v12 不发布，且同一冻结批次不补跑。其失败已通过 v13 做零调用离线处置：

1. 让结构化载荷按稳定的要求 ID 对齐，而不是依赖模型逐字复写概念表达；
2. 将缺失要求逐项返回并验证，任一要求无有效内容时显式失败；
3. 对行动项做编号归一化，避免 `1. 1.`；
4. 把结构化解析失败与证据遗漏加入离线回归样本；
5. 不再冻结新的精准度回放，版本链在 v13 工程收尾后关闭。

v13 处置详见
[`RL_PRECISION_UPGRADE_V13_FINAL_REPORT.md`](RL_PRECISION_UPGRADE_V13_FINAL_REPORT.md)。
本结果只验证 v12 定向修复，不改变云端 A/B/C/D 训练继续受预算约束的结论。
